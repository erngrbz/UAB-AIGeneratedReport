# Frontend Service

Modern user interface for the UAB Accident Report System built with Next.js App Router and TailwindCSS.

## 🛠 Tech Stack
- Next.js 16 (App Router) & React 19
- TailwindCSS 4 & Shadcn UI
- Lucide React & date-fns

## 🚀 Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Development Server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

3. **Production Build:**
   ```bash
   npm run build
   npm run start
   ```
